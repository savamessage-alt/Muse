## Полное описание

**Muse** — неофициальный клиент Яндекс Музыки для Android, созданный с вниманием к деталям. Один кодовая база работает и в браузере, и на Windows, и на Android.

### 🎵 Главные возможности

**Медиа-виджет уровня системы**
- Полноценное уведомление **MediaStyle** в шторке и на экране блокировки
- Обложка альбома, название трека и исполнитель
- Кнопки: **Предыдущий ▸ Пауза/Играть ▸ Следующий ▸ В избранное (♥)**
- Прогресс-бар (seekbar) с перемоткой
- Работает в фоне после закрытия приложения

**Интуитивные свайпы везде**
- **Левый край экрана → Назад** (на всех страницах, кроме корневых вкладок)
- **Строка трека: влево → меню действий, вправо → лайк/снять лайк**
- **Обложка в развёрнутом плеере: влево/вправо → след./пред. трек, вниз → свернуть**

**Умный плеер**
- Очередь воспроизведения с автодополнением **похожими треками** (когда очередь заканчивается)
- Сохранение очереди и позиции в `localStorage` — после перезапуска музыка продолжает с того же места
- Защита от бесконечного перелистывания: при 3 ошибках подряд плеер останавливается с уведомлением

**Лайки, которые работают**
- Мгновенная визуальная обратная связь (пустое ↔ заполненное сердечко)
- Синхронизация с аккаунтом Яндекс Музыки
- Лайк доступен и в системном виджете

**Полноценный интерфейс**
- «Моя волна», радиостанции, поиск, плейлисты, лайки, история
- Альбомы и исполнители с популярными треками
- Тёмная тема, русскоязычный интерфейс
- Адаптивный дизайн для любых экранов (телефоны, планшеты)

### 🛠 Технические детали
- **React 19 + TypeScript + Vite + Zustand + HashRouter**
- **Capacitor** для нативной Android-сборки
- Нативный **Foreground Service** с **MediaSession** для виджета
- Web Media Session API для десктопной версии
- OAuth Device Flow (вход через код на ya.ru/device)
- Автообновление токена через refresh_token

### ⚠️ Важно
Неофициальный клиент. API Яндекс Музыки не документировано и может меняться. Без подписки «Яндекс Плюс» часть треков доступна только в 30-секундных превью.

## Политика конфиденциальности
Приложение не собирает персональные данные. Токен OAuth хранится локально в `localStorage` и используется только для запросов к API Яндекс Музыки. См. `PRIVACY_POLICY.md` (при необходимости).
